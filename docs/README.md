# Documentación de AlertaBarrio

Estos documentos describen el diseño lógico acordado para el piloto en Yungay y los puntos pendientes de implementación:

- [Datos y permisos](../database/diseno-datos-permisos.md): alcance territorial, anonimato, estados, VIF y roles.
- [Diccionario de datos](../database/diccionario-datos.md): entidades, campos y restricciones propuestas para PostgreSQL.
- [Modelo de relaciones](../database/modelo-relaciones.md): vínculos entre las entidades.

Se conservan como documentación de diseño. No crean tablas, no conectan un servidor ni cambian las funciones de la demostración. Consulta el [README principal](../README.md) para abrir la maqueta y conocer sus límites.
